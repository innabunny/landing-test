# Адаптивный лендинг

Адаптивная вёрстка информационной страницы об онлайн-голосовании в Москве по макету Figma.

### 🔗 Демо

**[Посмотреть сайт](https://innabunny.github.io/landing-test/)**

### 🛠 Технологии

- HTML5 — семантическая разметка.
- SCSS — стилизация и адаптивная вёрстка.
- JavaScript (ES6+) — интерактивность и анимации.
- Vite — сборка проекта.

### ✨ Реализовано

- Адаптивная вёрстка для мобильных устройств, планшетов и десктопов.
- Поддержка портретной и горизонтальной ориентаций.
- Компонентная организация HTML и SCSS.
- Навигация по разделам страницы.
- Мобильное меню.
- Hover-эффекты интерактивных элементов.
- Анимация появления элементов при прокрутке с использованием Intersection Observer API.
- Поддержка `prefers-reduced-motion`.

### 🚀 Локальный запуск

Для запуска проекта необходим Node.js и npm.

Клонировать репозиторий:

```bash
git clone https://github.com/innabunny/landing-test.git
```

Перейти в директорию проекта:

```bash
cd landing-test
```

Установить зависимости:

```bash
npm ci
```

Запустить сервер разработки:

```bash
npm run dev
```

### 📦 Сборка

Создать production-сборку:

```bash
npm run build
```

Предварительный просмотр сборки:

```bash
npm run preview
```

### 🌐 Публикация

Проект публикуется на GitHub Pages с помощью GitHub Actions.
